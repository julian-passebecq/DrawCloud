# S001 — Trustworthy single-page AI round-trip

State: READY_FOR_DEV. Lead decision: 2026-09-08. Baseline: `409d82415f17cfe899267bd981c317067a798d59`.

## Outcome and scope

A user can load one of the five shipped templates or a supported local file, copy its semantics, stage an AI patch, understand its effects, apply it, undo it and download the actual working diagram. Invalid or unsupported inputs leave the current work intact. Development and CI can prove this with repeatable tests.

Deliver backlog items DC-001 through DC-007. Implement all three passes in one sustained assignment. The checkpoints below are not requests for user confirmation. No fixed hourly estimate is imposed; use outcome completion rather than elapsed time to end a pass.

Excluded: compressed decoding, multiple pages/layers, groups/wrapped cells, arbitrary Draw.io compatibility, external editor embedding, persistent drafts, protocol v2, provider icon expansion, backend, Git writes or hosted AI calls. Explicitly rejecting unsupported inputs is part of this sprint.

## Contract the developer must implement

### Supported input profile

- Accept a standalone `mxGraphModel` or an `mxfile` containing exactly one `diagram` with one direct, uncompressed `mxGraphModel`. Preserve the original supported envelope and its metadata.
- The graph has exactly one direct `root`, one structural root cell with no parent, one layer cell parented to that root, and zero or more direct vertex/edge cells parented to that layer. Structural root/layer IDs are nonempty and need not be `0`/`1`; discover them. Every cell has a unique nonempty ID. A valid empty graph is accepted.
- Vertices have `vertex="1"`; edges have `edge="1"`; reject ambiguous or unclassified nonstructural cells. Vertex geometry has one direct `mxGeometry` and finite absolute position/size when present, with positive width/height. Permit missing x/y/width/height and retain the current semantic defaults (0/0/120/60) without writing defaults into the source. Reject relative vertex geometry in this profile.
- Edges must reference existing vertices by both source and target; reject dangling/free-standing endpoints in S001. Preserve edge geometry, points, labels and unknown attributes. Reject duplicate direct geometry elements.
- Reject malformed XML, unrelated XML, document types/entity declarations, compressed diagram payloads, multiple pages, multiple layers, parent cycles, nested/group vertices and wrapper elements such as `object`/`UserObject`. Do not silently discard graph-root child elements that fall outside this profile. Harmless whitespace/comments and metadata attributes are preserved; opaque children within supported geometry can be preserved without interpreting them.
- Initial resource bounds: 5 MiB UTF-8 XML, 10,000 cells including structural cells, 1 MiB UTF-8 patch text, 500 operations. Check file size before reading where possible; validate actual content and post-patch output as well. Empty/over-limit inputs yield readable diagnostics. These are guardrails, not a guarantee that every allowed worst-case combination is fast.
- Errors distinguish malformed input, unsupported document features, invalid graph, invalid patch, missing reference, duplicate ID and resource limit. Include a 1-based operation index/ID when relevant. Explain how to export uncompressed XML when appropriate; do not claim all rejected files are corrupt.

### Patch v1

Accept `unknown` at the public patch boundary. Validate that the envelope is an object with exactly `format` and `operations`, with `format: "drawcloud-patch-v1"` and an array. Reject null, scalars, arrays as the envelope, unknown keys and unknown operation names. Each operation is an object with only the fields below. Reject missing required fields and incorrect types; do not coerce numbers, strings, nulls or booleans. Optional fields may be absent; null is not absence. IDs must be nonempty, not whitespace-only, and compared exactly without trimming or renaming. Labels may be empty strings. Preserve opaque IDs containing punctuation or Unicode using an ID map instead of constructing selectors.

| Operation | Required fields beyond `op` | Optional fields | Semantics |
| --- | --- | --- | --- |
| `updateNode` | `id: string` | `label: string`, `style: string` | Existing vertex only. Replace only supplied attributes; replacing style replaces the full style string. No supplied changes is a valid no-op. |
| `addNode` | `id: string`, `label: string` | `style: string`, finite numeric `x`, `y`, positive `width`, `height` | ID must be unused across all cells; append to discovered layer. Defaults: x/y 80, width 160, height 64; retain current default node style. |
| `deleteNode` | `id: string` | None | Delete the existing vertex and every incident edge. Report implicit edge removals. |
| `connect` | `id: string`, `source: string`, `target: string` | `label: string`, `style: string` | New exact ID, existing vertex endpoints at this point in the transaction. Retain current default edge style/geometry. Self-loops and distinct-ID parallel edges are allowed. |
| `deleteEdge` | `id: string` | None | Delete an existing edge; missing edge is an error, including one removed earlier by deleteNode. |

Operations execute in listed order on the candidate graph. Adding then referencing a new node is valid. Referencing it before creation is invalid. A deleted ID may be reused later in the same transaction if then unused. Failure of any operation rejects the whole patch; never skip an operation or return partial success. An empty operations array returns unchanged XML and creates no undo entry.

Validate the resulting graph and semantic projection before returning a candidate. Keep `drawioToAi`'s v1 format/nodes/edges contract for supported inputs. This sprint must not pretend that v1 encodes page identity or detects old AI responses.

### Workspace behavior

- Keep source XML, filename, source provenance and revision together. Derive semantic JSON from the same validated snapshot; avoid independent state values drifting apart.
- Template XML comes from the current build/checkout. Prefer explicit raw imports for the five files; they stay under `templates/` as the single source. Repository links may still point to `main`, but are visibly repository-original links, not the local draft.
- Load/import fully validates before committing state. New load/import intent supersedes older pending requests across both sources. Use a shared sequence token or equivalent. Failures preserve the previous workspace and show an error; obsolete responses cannot change document or status. Avoid allowing a pending load to silently overwrite edits made while it was pending: either disable editing during replacement or invalidate that pending request on edits.
- When replacing a modified workspace, provide a cancelable discard step in the app. Reset history only when the replacement succeeds. Keep the imported filename for download. “Modified” means diverged from the loaded source; undoing back to it clears that state. A download does not prove the user saved or archived the file.
- “Review patch” validates and stages the full candidate without committing it. Show ordered operation IDs/types and changed fields, including implicit edge deletions. Escape values as text. Do not call this a visual layout preview.
- “Apply” commits only the reviewed candidate tied to the exact workspace revision AND patch text. Changing either invalidates review. Applying consumes the candidate so a double click cannot reapply it.
- Undo restores the previous exact XML and derived semantics. Keep at most 10 prior snapshots and 25 MiB total UTF-8 snapshot data; drop oldest entries when necessary. Disable undo when empty. Show when older history was dropped. Redo and persistence are out of scope. Failed/no-op patches do not add history.
- Download serializes the current supported XML with correct filename and MIME type. Manage object URL lifetime so the browser can complete the download; test the artifact contents.
- Catch clipboard and loading failures, expose readable status with appropriate success/error semantics, keep AI text selectable as a copy fallback, and label form controls. Disable actions without required input. No link promises to open the modified draft if it only opens GitHub source. Explain download/open/reimport as the supported current-draft path.
